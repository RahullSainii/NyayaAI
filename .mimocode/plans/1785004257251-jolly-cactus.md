# Plan: Add ChatGPT-style Chat Features to NyayaAI

## Context

The ChatBubble component (`frontend/src/components/ChatBubble.jsx`) already has UI for **all** the requested features (Copy, Thumbs Up/Down, Share, Regenerate, Read Aloud, Branch in new chat, Sources badge), but `Chat.jsx` never passes the required callbacks (`onRegenerate`, `onBranch`), making those buttons permanently hidden. Additionally, `Chat.jsx` has two bugs that break message sending entirely.

The goal is to: (1) fix the broken chat flow, (2) wire up all the dead-code features so they actually work, and (3) make sessions persist messages.

---

## Bug Fixes (Prerequisite)

### Fix 1: `sendMessage` is undefined (`Chat.jsx:169-170`)
`handleSend` and `handleSuggestionClick` call `sendMessage(input)` / `sendMessage(text)` but `sendMessage` is never declared. The actual logic lives in `streamAssistantReply`.

**Fix:** Define `sendMessage(text)` that:
- Adds user message to `messages` state
- Calls `streamAssistantReply(text)`
- Updates the active session title from the first user message

### Fix 2: `trimmed` is undefined (`Chat.jsx:97`)
`streamAssistantReply` sends `{ query: trimmed }` but `trimmed` is never defined.

**Fix:** Change to `{ query: query.trim() }` (use the function parameter).

## Feature Implementations

### Feature 1: Regenerate Response
**Files:** `Chat.jsx`, `ChatBubble.jsx` (already has UI)

**Behavior:** Re-sends the last user query, replacing the last AI response.

**Implementation in `Chat.jsx`:**
- Add `handleRegenerate` function that:
  1. Finds the last user message in `messages`
  2. Removes the last AI message from state
  3. Calls `streamAssistantReply(lastUserMessage.content)`
- Pass `onRegenerate={handleRegenerate}` to the last AI `ChatBubble`

### Feature 2: Branch in New Chat
**Files:** `Chat.jsx`, `ChatBubble.jsx` (already has UI)

**Behavior:** Creates a new chat session with the current conversation up to this point.

**Implementation in `Chat.jsx`:**
- Add `handleBranch` function that:
  1. Creates a new session via `handleNewChat()`
  2. Copies all messages up to and including the branching message into the new session
  3. The new session starts with those messages (not just the welcome message)
- Pass `onBranch={() => handleBranch(messageIndex)}` to each AI `ChatBubble`

### Feature 3: Read Aloud
**Files:** `ChatBubble.jsx` (already fully implemented)

No changes needed — this feature already works via `window.speechSynthesis` with `en-IN` locale. It's accessible through the "..." menu.

### Feature 4: Sources Panel
**Files:** `ChatBubble.jsx` (already has source pills), `Chat.jsx`

**Behavior:** Clickable source badges that expand to show the citation details.

**Enhancement:**
- Make source pills clickable to toggle an expanded view showing `text_snippet`
- Add a tooltip/popover on hover or click showing the citation snippet
- Style: use the existing `surface-glass` pattern for the popover

### Feature 5: Session Persistence (Messages)
**Files:** `Chat.jsx`

**Behavior:** Switching sessions saves/restores messages.

**Implementation:**
- Add a `sessionMessages` ref or state that maps session IDs to message arrays
- On session switch: save current messages to the map, load the target session's messages
- On new chat: initialize with `[WELCOME_MESSAGE]`
- This is client-side only (no backend changes needed for now)

### Feature 6: Thumbs Up/Down Feedback
**Files:** `ChatBubble.jsx`

**Behavior:** Already toggles locally. No backend endpoint exists.

**Keep as-is** — local-only feedback is functional and matches the screenshot. No backend changes requested.
